1. ¿ Qué es CSS y para qué se usa?

CSS son las siglas de hojas de estilo en cascada.
Las hojas de estilo es una tecnología que nos permite controlar la apariencia de una página web.
Se usa justamente para eso, para darle la apariencia que queremos a nuestro sitio web, estilos como el tamaño, fuentes, color, espaciado entre textos y recuadros así como el lugar donde disponer texto e imágenes en la página.

2. CSS utiliza reglas para las declaraciones de estilo, ¿cómo funcionan?

Funcionan mediante un selector y un conjunto de declaraciones. Tiene la siguiente forma:
selector{
    propiedad: valor;
}

por ejemplo: 
p {
    color: blue;
    font-size: 20px;
}

3. ¿ Cuáles son las tres formas de dar estilo a un documento?

*Directamente a la marca
*En el head de la página
*Agrupar las reglas de estilo en un archivo independiente con extensión .css

4. ¿ Cuáles son los distintos tipos de selectores más utilizados?
Ejemplifique cada uno.

    1) Selector universal: El selector universal, escrito "*", se corresponde con el nombre de cualquier tipo de elemento. Es equivalente con cualquier elemento en la estructura del documento.
    Por ejemplo:

        * {
            margin: 0;
            padding: 0;
        }
    
    2) Selectores de tipos: Un selector de tipo se corresponde con el nombre de un tipo de elemento en el lenguaje del documento. Un selector de tipo equivale con cada instancia del tipo de elemento en la estructura del documento.
    Por ejemplo:

    H1 { font-family: sans-serif }

    3) Selectores de descendientes:Selecciona elementos que se encuentran dentro de otro elemento.
    Por ejemplo:

    div p {
        color: purple;
    }

    4) Selectores de hijos: Un selector de hijo equivale cuando un elemento es el hijo de algún elemento. Un selector de hijo se compone de dos o más selectores separados por ">".
    Por ejemplo:

    /* La siguiente regla asigna el estilo de todos los elementos P que son hijos de BODY */
    BODY > P { line-height: 1.3 }

    5) Selectores de hermanos adyacentes: Selecciona un elemento que está inmediatamente después de otro elemento y que comparte el mismo padre.
    Por ejemplo:

    h2 + p {
        color: red;
    }

    6) Selectores de atributos: Selecciona elementos que poseen un determinado atributo.
    Por ejemplo:

    input[type="text"] {
        border: 1px solid black;
    }

    7) Selectores de clases: Selecciona los elementos que tienen una determinada clase. Se identifica con . (un punto).
    Por ejemplo:

    .pastoral { color: green }  /* todos los elementos con class~=pastoral */

    8) Selectores de ID: Los selectores ID de CSS equivalen a una instancia del elemento basado en su identificador. Un selector ID de CSS contiene un "#" seguido inmediatamente por el valor de ID.
    Por ejemplo:

    /* El siguiente selector de ID equivale al elemento H1 cuyo atributo ID tiene el valor "capitulo1" */
    H1#capitulo1 { text-align: center }
